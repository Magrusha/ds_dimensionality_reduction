# Снижение размерности

Обучение без учителя на трёх прикладных задачах: рекомендации книг, визуализация рукописных цифр и сжатие изображений. Разобраны и сравнены методы линейного и нелинейного сжатия признаков, проведён системный анализ методов по единым критериям.

## Ключевая реализация
- Сравнение методов матричной факторизации (SVD, PCA, NMF) и манифолд-обучения (t-SNE, UMAP, LLE) на одних и тех же данных.
- Разреженная матрица взаимодействий «пользователь–книга» и сжатие признаков перед обучением моделей.
- Сжатие изображений через низкоранговое SVD-приближение с оценкой качества по структурному сходству (SSIM) и спектру сингулярных значений.
- Системное сравнение всех методов по критериям: потребление памяти, степень сжатия, скорость, интерпретируемость и число гиперпараметров.

## Стек технологий
- **Язык:** Python 3
- **Библиотеки:** NumPy и SciPy (SVD, разреженные матрицы), Pandas, Scikit-learn (PCA, SVD, NMF, t-SNE, LLE, модели), UMAP-learn, scikit-image (SSIM), Matplotlib (визуализация).

## Что реализовано
**1. Теоретическая часть:**
- Разбор проклятия размерности и того, какие модели страдают от него сильнее всего.
- Объяснение различий PCA и SVD, NMF и SVD.
- Описание структуры Locally Linear Embedding.

**2. Рекомендации книг (Book Recommendation Dataset):**
- Построение разреженной матрицы взаимодействий пользователь–книга.
- Разделение на train/valid/test, обучение линейной модели и случайного леса для предсказания возраста.
- Сжатие признаков через PCA и UMAP, повторное обучение моделей, сравнение времени обучения и качества.

**3. Визуализация MNIST:**
- Представление каждой цифры вектором и сжатие в 2D шестью методами: PCA, SVD, Randomized-SVD, t-SNE, UMAP, LLE.
- Сравнение методов по качеству разделения классов цифр.

**4. Сжатие изображений через SVD:**
- Декомпозиция матрицы изображения, вариация ранга, восстановление.
- Анализ спектра сингулярных значений и объяснённой дисперсии, оценка качества реконструкции через SSIM.

**5. Обнаружение фона в видео:**
- Представление видеопоследовательности матрицей и низкоранговое SVD-приближение для выделения фона.

## Анализ результатов
- t-SNE хорошо сохраняет локальную структуру и разделяет классы на малых размерностях, но не отражает глобальную геометрию и медленно сходится; UMAP быстрее и лучше сохраняет глобальную структуру; LLE чувствителен к шуму и разреженным областям.
- PCA и SVD дают линейные, быстрые и интерпретируемые представления; NMF даёт разреженные компоненты, удобные для интерпретации, но не подходит для борьбы с проклятием размерности на больших матрицах.
- При сжатии изображений через SVD качество растёт с рангом до порога, после которого добавление новых компонент почти не меняет SSIM — это видно по плато на графике объяснённой дисперсии.
- Сводная таблица методов по памяти, степени сжатия, скорости, интерпретируемости и числу гиперпараметров показывает, что PCA выигрывает по скорости и простоте настройки, а нелинейные методы — по качеству визуального разделения.

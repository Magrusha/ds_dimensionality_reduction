Классификация с редкими признаками

Загрузите "Набор данных для рекомендаций книг" (источник).
Создайте матрицу взаимодействий между пользователями и книгами. Используйте разреженные матрицы.
Разделите набор данных на обучающую, проверочную и тестовую части.
Постройте линейную модель и модель случайного леса для прогнозирования возраста пользователя на основе взаимодействий между пользователями и книгами. Не забудьте выбрать оптимальные параметры.
Используйте метод главных компонент и UMAP для снижения размерности признаков.
Постройте линейную модель и модель случайного леса на основе сжатых признаков.
Сравните время и качество подгонки моделей из iv и vi.



Визуализации

Загрузить набор данных MNIST (источник).
Представить каждое изображение цифры в виде вектора.
Преобразовать векторы до двух измерений с помощью метода главных компонент, сингулярного разложения, рандомизированного сингулярного разложения, метода тензорного сжатия, метода UMAP и метода LLE.
Предложите метрики и сравните модели по тому, насколько хорошо они разделяют классы цифр.



Сжатие изображений с помощью сингулярного разложения

Выберите 3 случайных изображения в оттенках серого и загрузите их в матрицу с помощью Python.
Разложите матрицу с помощью метода сингулярного разложения.
Измените ранг, вычислите низкоранговое приближение исходной матрицы и постройте восстановленное изображение. Используйте до 10 различных рангов. Как выглядит спектр сингулярных значений и сколько мод необходимо для качественной реконструкции изображения?
 Постройте график зависимости объясненной дисперсии от ранга. Объясните, что такое «объяснённая дисперсия».



Обнаружение фона с помощью сингулярного разложения

Загрузить «Video_008.avi» (исходный файл — bmc_real.zip).
Представить видео в виде матрицы и разложить её с помощью сингулярного разложения.
Воспроизвести первый кадр с помощью аппроксимации низкого ранга. Какой ранг следует использовать, чтобы получить фон?




Отправка
Сохранить одну из моделей из раздела «Визуализация» в задании. Ваш коллега загрузит его и с его помощью сожмет одну из рукописных цифр. Сжатый вектор должен иметь те же значения. Подготовьте фрагмент кода, демонстрирующий, как загрузить, как применить и каким должен быть результат.
В вашем репозитории должны быть одна или несколько записных книжек с вашими решениями.

Используя набор данных для распознавания выражений лиц, подгоните модель уменьшения размерности для сжатия лиц. Используя изображения, попробуйте превратить грустное лицо в улыбающееся и наоборот.
